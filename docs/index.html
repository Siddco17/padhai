Fix gaps (just-in-time)

You barely passed EE, EDC, NS; Physics was FF → summer. Cap catch-up at ~2–3 hrs/week.

For ACD ← EE + EDC

  1. Sources, KVL/KCL, voltage divider
  2. Thevenin / Norton
  3. Diode as switch / clipper intuition
  4. BJT as rough current amp (don’t fear 741 guts)
  5. Gain, Zin, Zout meaning
Skip full hybrid-π grinding unless the lecturer demands it. Use Alexander–Sadiku circuits PDF in prereq + Gaikwad ch.1–2.

For EMFT ← Physics

  1. Unit vectors; what a field is
  2. Dot & cross (work / flux / perpendicular)
  3. Cartesian first, then cylindrical/spherical
  4. Coulomb → Gauss from Sadiku early chapters
Do the tutorial sheet the same day. Reading alone repeats the Physics failure mode.

If NS was networks

  • R/L/C impedance
  • Series/parallel RC
  • Time constant
  • Hand-wavy H(jω) — pairs with SnS
