## Open in Google Colab

1. Go to [Google Colab](https://colab.research.google.com/).
2. **File → Upload notebook** and choose  
   `sem3/07-fundamentals-of-ml-lab/scripts/linear_regression_decision_tree.ipynb`
3. **Runtime → Run all**.

The notebook loads `data/insurance.csv` if you upload that too. If you only upload the `.ipynb`, it still runs: it downloads the same Kaggle insurance table from a public mirror.

Optional official Kaggle download: Kaggle → Account → Create New Token → in Colab uncomment the `files.upload()` cell and upload `kaggle.json`.
