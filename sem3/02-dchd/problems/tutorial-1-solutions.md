# DCHD Tutorial 1 — Solutions

**Course:** ECLA201 / ECL216 Digital Circuits and Hardware Design · **Hub:** [[DCHD]] · [[Number systems]]

Parentheses in a fractional part mark a repeating block, e.g. `0.1(4)` = 0.1444…

## Methods (use these in the tutorial)

**Integer, source → decimal:** positional weights. `(dₙ…d₀)_b = Σ dᵢ bⁱ`.

**Integer, decimal → dest:** repeated division by dest; remainders are digits LSB→MSB.

**Fraction, decimal → dest:** repeated multiply by dest; integer parts are digits after the point.

**Binary ↔ octal:** group bits in 3s (pad integer left, fraction right).

**Binary ↔ hex:** group bits in 4s.

**Any other pair:** convert source → decimal (exact), then decimal → dest.

## Word problems

### 1. legacy hex address → binary for 0/1 controller

Given `(3A7F)₁₆`.

Each hex digit → 4 bits: `3=0011`, `A=1010`, `7=0111`, `F=1111`.

`3A7F₁₆ = 0011 1010 0111 1111₂`

Leading zeros may be dropped: `11101001111111₂`. For a 16-bit address, keep all four nibbles.

**Answer:** `(3A7F)₁₆ = (0011 1010 0111 1111)₂`  (binary)

### 2. octal logger code → decimal for upgraded software

Given `(73456)₈`.

Positional: `7·8⁴ + 3·8³ + 4·8² + 5·8¹ + 6·8⁰`.

**Answer:** `(73456)₈ = (30510)₁₀`  (decimal)

### 3. base-5 register → hex debug software

Given `(3241302)₅`.

Base-5 → decimal, then decimal → hex (or base-5 → binary → group by 4).

**Answer:** `(3241302)₅ = (DA13)₁₆`  (hexadecimal)

### 4. hex frame ID → octal hardware

Given `(7B9D)₁₆`.

Hex → binary (4 bits/digit), then group bits in 3s for octal.

**Answer:** `(7B9D)₁₆ = (75635)₈`  (octal)

### 5. base-5 measurement → decimal QC software

Given `(431204)₅`.

**Answer:** `(431204)₅ = (14554)₁₀`  (decimal)
