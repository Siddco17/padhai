# CSL2XX — Fundamentals of Machine Learning (Annexure III)

**Hub:** [[FoML]] · [[FoML Lab]]

**Programme:** B.Tech · **Type:** OC · **L-T-P:** 3-0-2 · **Credits:** 4  
**Pre-requisite:** CSL101 Computer Programming  
**Evaluation:** Mid-sem 25% · End-sem 50% · Lab 25%

## Objectives
- Introduce basic ML concepts and techniques
- Use recent ML software for practical problems
- Recognize when ML helps real-world problems

## Course outcomes
- **CO1** Understand popular ML algorithms + math foundations
- **CO2** Implement algorithms with basic ML libraries
- **CO3** Apply ML across domains
- **CO4** Exposure to high-level ML libraries/frameworks

## Detailed syllabus

### 1. Mathematics for Machine Learning (~3 weeks) — CO1,2
- Basic probability, Bayes rule, continuous/discrete
- Parameter estimation: method of moments, MLE
- Naive Bayes / Gaussian NB (single + multiple features)
- Decision boundary, error estimation, precision, recall, confusion matrix

### 2. Introduction to Machine Learning (~2 weeks) — CO1
- Motivation and role of ML
- Paradigms: supervised, unsupervised (+ brief others)
- Training, testing, validation; error estimation
- Classification, regression, clustering

### 3. Basics of Machine Learning (~2 weeks) — CO1,2
- Linear classifiers
- Linear regression; errors, losses, correlations
- Train / validation / test
- Generalization and overfitting

### 4. Neural Network Learning (~3 weeks) — CO1–4
- Intro to ANN
- Backpropagation, gradient descent, perceptron/delta learning
- MLP for classification and regression
- Regularization and early stopping

### 5. Selected Algorithms (~2 weeks) — CO1–4
- Non-parametric: decision trees; nearest neighbors / KNN
- Unsupervised: k-means; hierarchical clustering

### 6. Applications to Engineering (~2 weeks) — CO2–4
- Feature generation (images, time series), selection, dimensionality reduction, PCA
- Survey of domain problems and common ML models
