# Naive Bayes

Assume features independent given the class. Classify by max `P(y) ∏ P(x_i|y)`. Gaussian NB: each P(x_i|y) is a normal.

## Why it matters here

Math-for-ML unit. If probability is skipped, this unit drowns you. Decision boundary is where posteriors tie.
