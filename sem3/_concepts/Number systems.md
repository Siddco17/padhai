# Number systems

Integer source → decimal: positional weights. Decimal → dest: repeated divide, remainders LSB→MSB. Fraction: repeated multiply. Binary↔octal groups of 3; binary↔hex groups of 4.

## Why it matters here

[[DCHD]] Tutorial 1–3 live in the crash course. Redo conversions **by hand**.

## Exam form

Mark repeating fractions with parentheses, e.g. `0.1(4)`. Any odd pair: source → decimal (exact) → dest.
