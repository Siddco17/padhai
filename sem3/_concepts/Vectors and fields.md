# Vectors and fields

A **field** is a value at every point. A **vector field** (E, H) has direction too. Physics FF → this is the [[EMFT]] hole. Start Cartesian; add cylindrical/spherical when the syllabus does — [[Coordinate systems]].

## Why it matters here

Coulomb, Gauss, Biot–Savart all *are* vector fields. If “field” is still a vibe word, Hayt ch.1–3 before Sadiku waves.

## Exam form

Name the quantity, the point, and the unit vector. Work and flux use [[Dot and cross product]]. Differential operators: [[Gradient divergence curl]].
