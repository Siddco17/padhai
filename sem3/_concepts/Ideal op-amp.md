# Ideal op-amp

Infinite gain, infinite Zin, zero Zout, zero input current, infinite CMRR/bandwidth. Negative feedback + finite output ⇒ **virtual short**: `v+ ≈ v−` (and [[Virtual ground]] if one input is 0).

## Why it matters here

Every [[ACD]] configuration. Real 741: offset, bias current, slew, finite GBW — know the names for the parameter unit.

## Exam form

Ideal analysis first, then one non-ideality if asked. Source resistance via [[Thevenin and Norton]].
