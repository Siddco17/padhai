# Finite state machines

States + transitions + outputs. Design: state diagram → encoding → excitation tables → race-free (no two bits change on a critical arc unless the code is Gray / one-hot as required). ASM charts for controllers.

## Why it matters here

DCHD units 2–3. Lab sequential experiments. Mistake log: race, Mealy/Moore, timing — see [[sem3/_meta/ten-pointer-plan|10-pointer]] playbook.
