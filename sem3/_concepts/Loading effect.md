# Loading effect

The meter / next stage **steals** current, so the voltage you wanted (open-circuit) drops. Model source as [[Thevenin and Norton]]: error vanishes when `Rload ≫ Rth`.

## Why it matters here

MNI lecture PDF you already have. Also every [[ACD]] sensor + op-amp input.
