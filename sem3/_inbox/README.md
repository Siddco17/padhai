# Inbox

Obsidian new notes land here (`Cmd+T` templates: Lecture / Lab / Concept / One-pager).

Pending Beeper downloads land in `pending/`. Approval queue JSON is in `queue/`.
After you approve via `tools/beeper-ingest/ingest.py review` (or `auto`), academic PDFs/photos go into the matching course `resources/` folder.

- `unsorted/` — temporary hold when the course is unclear  
- `notices/` — institute / FY / admin PDFs (fees, seating, summer term, etc.), not course notes
