## Essentials first

| Tool | Why | Link |
|------|-----|------|

## Sem 3 lab / course software

| Tool | Used for | Link / notes |
|------|----------|--------------|
| **NI Multisim** | DCHD, ACD, EDC-style circuit sim | Telegram channel files + [install video](https://youtu.be/LTzF1oHlnp0) (see HackMD) |
| **Anaconda (Python 3)** | FoML lab, SnS scripts, general | https://repo.anaconda.com/archive/Anaconda3-2021.05-Windows-x86_64.exe — **add `bin` to Windows PATH** |
| **VS Code** | Editor for Python / HDL / notebooks | https://code.visualstudio.com/Download |
| **MySQL** | Later OOP-era course; keep if OC needs DB | Telegram channel (HackMD link) |
| **MATLAB R2018a** | SnS / DSP-style numeric work; heavy install | [Drive download](https://drive.google.com/file/d/11LLecsK9SIFPqSEJHg67iHgAnigov7Nd/view) + Telegram install video (HackMD) |
